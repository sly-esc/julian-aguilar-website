# Julián Aguilar — Brand spec

## System
Premium marca personal oscura — azul Oxford profundo como lienzo, dorado como acento único, blanco para aire y contraste.

## Tokens

```css
--bg: #0A1A30;
--surface: #0F2747;
--fg: #FFFFFF;
--muted: #8A9BB0;
--border: rgba(201, 162, 39, 0.2);
--accent: #C9A227;
```

## Typography

- **Display**: Montserrat Semibold, sans-serif
- **Body**: Lato, sans-serif

## Posture
- Dorado máximo 2 veces por pantalla
- Azul como base neutral (70%+), no decorativo
- Blanco para fondos de secciones alternas
- Sin degradados salvo iluminación sutil sobre oscuro
- Jerarquía de tipo sobre decoración
- Ritmo: oscuro → claro → fotográfico → oscuro
